cleaned CSV files from team members + 2 previously generated Parameter Group CSV files → 8 input CSV files → Run `build_impc_import_tables.R` → Automatically generate 18 `_import.csv` files → Import them into `data_base_merged` using DBeaver in the specified order.**

## Step 4: Obtain the 18 Exported CSV Files

Once the script runs successfully, it will automatically create the following folder:

```text
IMPC_Project/
└── database_import_revised/
```

This folder will contain 18 CSV files ending in `_import.csv`, along with additional execution reports.

**Only the 18 `_import.csv` files need to be imported into MySQL.**

## Step 5: Open DBeaver and Import the Data into MySQL

1. Open DBeaver and connect to MySQL.
2. Locate the `data_base_merged` database, (created using the **Final Version** of the SQL code at the end of `SQL.Rmd`)
3. Select **CSV** as the source and choose the matching `_import.csv` file.

**Important:** The primary key IDs generated by the R script must be imported as well. Do not allow MySQL to generate different IDs, as this may break the relationships between tables.

If a CSV file contains only column headers and no records, the corresponding MySQL table can remain empty.

In particular, if the optional `external_raw.csv` file is not provided, the 18th table, `parameter_group_external_data`, will be empty. This does not prevent the other tables from being imported.
